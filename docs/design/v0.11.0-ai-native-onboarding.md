# v0.11.0 AI 原生接入与任务管理

日期：2026-10-20。状态：实现完成，开发版验证与交付记录见 DEVELOPMENT_LOG。

## 目标与范围

- 用户将公开 Git 链接交给 Codex / WorkBuddy 后，可理解价值、安装应用并通过对话管理同步任务。
- 复用现有 FastAPI、账号服务、Device Flow 和同步服务，不引入模型服务或第二套同步引擎。
- GitHub README 作为产品主页；开发历史保存在 CHANGELOG / DEVELOPMENT_LOG。

## 调用契约

- 独立标准库 CLI 提供能力发现、JSON 参数、配置预览、结构化错误和明确下一步。
- 账号通过显式参数绑定到整次调用；只有一个账号时可自动选择，多账号时要求选择，不跟随 UI 活动账号。
- 授权复用现有应用注册、Device Flow 会话接口。用户完成扫码，AI 读取状态继续。
- 目录发现采用分页查询，支持飞书/Lark 文件夹链接；不默认递归全盘。
- 任务支持创建、读取、修改、暂停、恢复、删除、运行、等待结果、诊断和目录浏览。
- JSON 任务配置覆盖现有任务模型，包括忽略子目录和文件/文件夹方向规则。
- 首次默认仅下载、关闭删除联动。预览不写配置、不创建任务、不启动同步。
- 运行提交与同步完成分开；返回账号、任务 ID、运行时间及完成状态。
- 下载/上传频率沿用现有全局设置，明确标注影响全部任务；不伪装成独立任务频率。

## 分发与文档

- CLI 源码放入可独立复制的通用 Skill；仓库旧命令保留兼容入口。
- 安装包附带控制台 CLI；发布同时生成完整 Skill ZIP、校验文件和安装包选择说明。
- Codex 使用本地技能安装；WorkBuddy 使用技能导入。两者复用同一核心实现。
- 公共 AGENTS 增加使用/开发分流与本地规格缺失时的公开参考路径；本地规格继续禁止提交。
- README 保留价值、能力、边界、安装、AI 使用例子和文档导航；移出逐版本开发记录。
