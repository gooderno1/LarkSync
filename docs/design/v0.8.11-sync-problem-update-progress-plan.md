## 2. 正式版问题复盘

### 2.1 最新同步失败

- 2026-07-28 21:30:16 的周期上传检测到两个本地对象有变化。
- 两个对象都是 ROS 代码包 `resource/` 目录中的零字节标记文件。
- 当前文件上传器在 `file_size <= 0` 时抛出“文件大小不能为空”。
- 两个对象均失败后，本轮运行结果为：
  - `total=2`
  - `ok=0`
  - `failed=2`
  - `skipped=0`
- 同类失败在当天 18:36 和此前运行中已经出现，属于稳定复现，不是偶发网络故障。

### 2.2 问题中心重复与误分类

- 同一轮运行生成三条 `failed` 事件：
  - 两条具体对象失败。
  - 一条任务完成汇总失败。
- 问题分类器把三条事件都写成独立问题。
- 具体对象事件只包含“文件大小不能为空”，没有携带上传方向。
- 分类器只检查错误文本，因此把对象问题归入 `system`，没有归入 `upload`。
- 任务汇总事件也归入 `system`，造成一个根因显示成三个未解决问题。

### 2.3 更新下载体验差异

- LarkSync 当前下载接口直到整个文件下载和 SHA256 校验结束才返回。
- 页面只能显示“下载中”，不能显示真实完成比例、传输大小、速度或校验阶段。
- 下载内容直接写入最终文件名；进程中断时可能留下不完整文件。
- Codex Companion 使用明确的更新阶段，并展示：
  - 百分比。
  - 已传输大小与总大小。
  - 每秒下载速度。
  - 下载完成和安装阶段。

## 3. 设计目标

### 3.1 同步

- 合法零字节文件不能导致整轮同步失败。
- 明确告诉用户该对象为何没有上传。
- 不修改本地文件内容，不用填充字节伪造成功。
- 不把零字节跳过记录计为问题。

### 3.2 问题中心

- 活动事件回答“本轮发生了什么”。
- 问题中心回答“现在需要处理什么”。
- 任务运行汇总不重复成为文件问题。
- 对象失败必须结合运行触发方向分类。
- 页面必须区分对象问题、任务运行异常和内容冲突。

### 3.3 更新

- 下载过程中持续显示真实进度。
- 下载完成后单独显示安全校验阶段。
- 中断或失败不能把不完整文件当成可安装包。
- 已下载且校验通过的缓存继续复用。
- 不改变现有外部 helper 安装交接与自动重启机制。

## 4. 同步处理规则

### 4.1 零字节文件

当普通文件满足 `local_size == 0` 时：

1. 不调用飞书上传接口。
2. `skipped_files` 增加 1。
3. 写入 `skipped` 活动事件。
4. 事件说明固定为“空文件已跳过：飞书云盘不支持 0 字节文件”。
5. 日志记录任务 ID 与本地路径。
6. 不新增或更新云端映射。
7. 不修改本地文件。
8. 启动时的未映射文件扫描不把零字节文件加入待上传队列；文件后续变为非零时，watcher 或下一次扫描会按普通文件处理。

此规则适用于所有用户和所有普通文件，不依赖目录名、扩展名或个人任务。

验证样例：

- 输入：`resource/package_marker`，大小 0 字节。
- 结果：运行成功，`failed=0`、`skipped=1`，活动中可见跳过原因。

### 4.2 非零文件

- 继续执行现有简单上传或分片上传。
- 现有 SHA256、映射更新、旧云端副本清理逻辑不变。

## 5. 问题模型

### 5.1 问题层级

| 层级 | `object_kind` | 含义 | 是否进入问题中心 |
|---|---|---|---|
| 对象问题 | `sync_object` | 文件、文档或目录对象的具体同步失败 | 是 |
| 任务异常 | `task_run` | 没有更具体对象证据的任务级异常 | 是 |
| 运行汇总 | 不创建问题 | `完成: total=...` 形式的运行结果 | 否，仅留在活动管理 |
| 内容冲突 | `conflict` | 本地与云端版本分叉 | 是 |

### 5.2 运行汇总抑制

满足以下全部条件的事件视为运行汇总：

- 状态为 `failed`。
- 消息严格匹配：
  - `完成: total=N ok=N failed=N skipped=N`
- `failed > 0`。

处理方式：

- 事件继续保留在活动管理和运行详情。
- 问题刷新不为该事件创建问题。
- 旧版已生成的对应问题自动转为 `resolved`。
- 解决依据记录为 `workflow_summary_not_problem`。
- 原始问题、出现次数与证据不删除。

### 5.3 对象问题分类

分类优先级：

1. 授权与权限错误。
2. 删除、冲突等明确状态。
3. 错误文本中明确的上传、下载、转换、本地 IO、网络或远端特征。
4. 当错误文本无法确认方向时，使用运行触发方向：
   - `scheduled_upload`、`manual_upload` 等上传方向 → `upload`。
   - `scheduled_download`、`manual_download` 等下载方向 → `download`。
5. 错误文本和运行方向都无法确认时才归入 `system`。

验证样例：

- 事件消息：“文件大小不能为空”。
- 所属运行：`trigger_source=scheduled_upload`。
- 结果：分类为 `upload`，不是 `system`。

### 5.4 旧记录兼容

- 分类器版本提升到 `problem-classifier-v3`。
- 对仍处于未解决/处理中/等待/忽略状态的旧同步事件问题执行轻量重分类。
- 旧任务运行汇总问题自动结案。
- 旧具体对象问题更新类别、标题、摘要、操作族和层级。
- 旧“文件大小不能为空”对象问题按新零字节跳过规则自动结案，依据记录为 `zero_byte_file_now_skipped`。
- 历史证据不删除。
- 如新旧指纹已经对应同一问题，必须合并出现记录，不能制造重复项。

### 5.5 页面展示

问题队列每项增加层级标签：

- 对象问题
- 任务异常
- 内容冲突

诊断区域增加“问题层级”，并保持“问题分类”独立展示。

示例：

- 层级：对象问题
- 分类：上传失败
- 对象：`src/package/resource/package_marker`

## 6. 更新下载状态机

### 6.1 状态

| `phase` | 用户含义 |
|---|---|
| `idle` | 尚未检查 |
| `checking` | 正在检查更新 |
| `up_to_date` | 已是最新版本 |
| `available` | 有新版本可下载 |
| `downloading` | 正在传输安装包 |
| `verifying` | 下载完成，正在校验 SHA256 |
| `downloaded` | 已下载且校验通过 |
| `error` | 检查、下载或校验失败 |

### 6.2 进度字段

`progress` 包含：

- `percent`：`0–100`。
- `bytes_per_second`：从本次下载开始计算的平均传输速度。
- `transferred`：已经写入临时文件的字节数。
- `total`：优先使用 Release 资产大小，缺失时使用响应 `Content-Length`。

### 6.3 下载文件安全

1. 下载写入 `<安装包>.part`。
2. 每个数据块更新内存进度。
3. 页面通过状态接口轮询读取进度。
4. 下载完成后进入 `verifying`。
5. 校验通过后使用原子替换生成最终安装包。
6. 校验失败或下载异常时删除 `.part`。
7. 只有 `downloaded` 状态和有效 `download_path` 才允许安装。

### 6.4 并发

- 同一进程只允许一个更新下载任务。
- 自动下载和用户手动下载共享同一下载锁。
- 重复请求等待同一个受控下载流程，不并行写同一文件。

## 7. 页面交互

### 7.1 下载区域

下载时显示：

- 主状态：“正在下载安装包”。
- 百分比，例如 `42%`。
- `24.1 MB / 57.1 MB`。
- `3.8 MB/s`。
- 水平进度条。

校验时显示：

- 主状态：“下载完成，正在校验安全性”。
- 进度保持 100%。
- 安装按钮继续禁用。

下载完成时显示：

- 主状态：“安装包已下载并校验通过”。
- 启用“打开安装包目录”和“静默安装”。

失败时显示：

- 明确错误原因。
- 下载按钮恢复为“重新下载”。
- 不提供失效的安装入口。

### 7.2 可访问性

- 进度区域使用 `aria-live="polite"`。
- 进度条使用 `role="progressbar"`。
- 提供 `aria-valuemin`、`aria-valuemax` 和 `aria-valuenow`。
- 颜色之外必须同时提供文字阶段。

## 8. 测试计划

### 8.1 后端

- 零字节文件被跳过，不调用上传器，不计失败。
- 任务汇总失败不创建新问题。
- 上传运行中的无方向错误文本仍分类为上传问题。
- 旧任务汇总问题自动结案。
- 更新下载实时产生非零进度。
- 下载完成进入校验并原子生成最终文件。
- 校验失败删除临时文件并进入错误状态。
- 并发下载不会同时写同一目标。

### 8.2 前端

- 问题队列显示“对象问题”或“任务异常”层级。
- 诊断区同时显示层级和分类。
- 更新页在下载中显示百分比、大小、速度和进度条。
- 校验阶段文案与按钮禁用状态正确。

## 9. 非目标

- 本版本不修改飞书 API 或伪造第三方接口字段。
- 本版本不把零字节文件填充为 1 字节后上传。
- 本版本不删除历史活动、问题或证据。
- 本版本不重写现有更新安装 helper。
- 本版本不在用户正式数据库中执行开发期写入测试。
